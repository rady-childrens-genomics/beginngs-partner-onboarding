This is an implementation of the BeginNGS query outside of TileDB, which can be run in ICA Bench.

Inputs:
- Variants of Interest
- Mode of inheritance information
- Metadata file (gender information)
- Optional blocklist
- post-processed ms-vcf files generated by Illumina IGG (Iterative GVCF Genotyper) after DRAGEN analysis. These ms-vcf files contain already deduplicated variants and the multiallelic variants have been already split.

Requirements:
- bcftools
- python3
- csvkit (pip install csvkit)

To run the code, run bcftools_filter.sh. This processes each chromosome in parallel, with the following steps:

1. Use bcftools to filter the ms-vcf files by position
2. Launch genotype_count_bychrom.py:
	- Import the filtered vcf file into a pandas dataframe and merge with variants of interest to select only variants with specific "ALT"
	- Calculate the zygosity for each variant from the genotype
	- Compute compound heterozygous variants (look for co-occurring HETs in the same sample in the same gene, or HETs that accompany a HOM_ALTs in the same sample in the same gene)
	- Compute positive genotypes based on MOI and gender information
	- Compute diplotypes of observed variants
	
Outputs:
- Genotype counts
- Diplotype counts

### 100 Genomes Validation Test Output

The example genotype and diplotype output was obtained by running the query on 3,202 high-coverage (Illumina 30X) DRAGEN 1000 Genomes Project samples (PMID:36055201, DOI: 10.1016/j.cell.2022.08.004) aligned to GRCh38 with Illumina DRAGEN v.4.2.7.
Running the query in ICA Bench (standard-xlarge) for the 3,202 samples takes ~3 mins 50. It's important to fast mount the project folder within bench with: workspace-ctl data create-mount --source /data/project --mount-path /data/mounts/project
